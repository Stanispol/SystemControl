# SystemControl — СистемаКонтроля

Монолитное модульное приложение для управления дефектами на строительных объектах.

## Стек технологий
- **Фронтенд**: Vue.js, Axios, TailwindCSS
- **Бэкенд**: ASP.NET Core, Entity Framework Core
- **БД**: PostgreSQL
- **Аутентификация**: ASP.NET Identity + JWT
- **Инфраструктура**: Docker, GitHub Actions, CI/CD

## Запуск проекта
docker-compose up --build
